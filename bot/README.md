# Бот клуба: подписка, воронка, напоминания

Telegram-бот, который:

1. **Встречает** нового человека и сразу дарит «Барометр состояния» (мини-приложение из этого репозитория).
2. **Прогревает** серией из 6 сообщений за ~10 дней: состояние → психосоматика → Тень по Юнгу → деньги и род → приглашение → мягкое завершение.
3. **Принимает оплату** подписки: Telegram Stars с автопродлением или рубли через ЮKassa.
4. **Открывает доступ** в закрытый канал по личной одноразовой ссылке и **закрывает** его, когда подписка кончилась.
5. **Напоминает**: о продлении (за 3 дня и за 1 день), об окончании, а если человек сам попросит — каждый день «загляни в себя» в выбранное время.
6. **Возвращает** ушедших: через 2 и 6 дней после окончания подписки отправляет два бережных письма.

Все тексты лежат в `content.json`, их можно менять без программиста.

---

## Как это устроено

```
/start ──► приветствие + Барометр
   │
   ├─ через 2 ч ─► письмо 1 ─ 24 ч ─► урок 1 ─ 48 ч ─► урок 2 ─ 48 ч ─► урок 3
   │                                                          │
   │                                           24 ч ─► оффер ─ 72 ч ─► финал
   │
   └─ оплата ──► воронка останавливается ──► ссылка в канал
                     │
                     ├─ за 3 дня / за 1 день ─► напоминание
                     └─ срок вышел ─► исключение из канала ─► письма «возврата»
```

Расписание хранится в базе, поэтому бота можно перезапускать: ничего не потеряется.

## Запуск за 15 минут

### 1. Создай бота
В Telegram открой **@BotFather** → `/newbot` → скопируй токен.

### 2. Выбери способ оплаты

| | **Telegram Stars** (`stars`) | **ЮKassa** (`provider`) |
|---|---|---|
| Автопродление | ✅ каждые 30 дней, само | ❌ человек платит вручную, бот напоминает |
| Подключение | ничего не нужно | договор с ЮKassa, токен в @BotFather → Payments |
| Деньги | звёзды → вывод через Fragment (в TON) | рубли на расчётный счёт |
| Чеки 54-ФЗ | не нужны от тебя* | бот передаёт данные для чека |
| Цена | `price_stars` | `price_rub` |

\* *Это моё понимание, а не юридическая консультация. По налогам и выводу звёзд уточни у своего бухгалтера.*

**Важно:** правила Telegram требуют продавать цифровые товары и услуги внутри Telegram за Stars. Подписка на закрытый канал с материалами — это цифровая услуга. Поэтому для работы внутри Telegram я рекомендую **Stars**. ЮKassa остаётся на твоё решение. Правила меняются, поэтому перед запуском перечитай актуальные условия Telegram.

### 3. Закрытый канал (по желанию)
Создай приватный канал → добавь бота **администратором** с правами «Приглашать пользователей» и «Блокировать пользователей».
Чтобы узнать ID канала, перешли любой пост из канала боту **@userinfobot**. ID выглядит так: `-100…`.

### 4. Установи на сервер одной командой

Подключись к серверу по SSH и выполни:
```bash
curl -fsSL https://raw.githubusercontent.com/olgakharu/-/claude/friendly-ride-qsxvyk/bot/deploy/install.sh | sudo bash
```
Скрипт сам поставит всё нужное, спросит токен и ID, запустит бота и включит автозапуск.
Повторный запуск той же команды обновляет бота до последней версии из GitHub. Настройки и база при этом сохраняются.

Переключить оплату на ЮKassa (или обратно на звёзды):
```bash
curl -fsSL https://raw.githubusercontent.com/olgakharu/-/claude/friendly-ride-qsxvyk/bot/deploy/install.sh | sudo bash -s -- --payments
```

### Или вручную (для разработки)
```bash
cd bot
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env        # и заполни .env
python main.py
```

Бот должен работать круглосуточно, поэтому его запускают на сервере: подойдёт любой VPS за 200–400 ₽ в месяц, Railway, Timeweb Cloud и т. п.

## Ссылки с метками (откуда пришли люди)

`https://t.me/ИМЯ_БОТА?start=insta` → в `/stats` увидишь, сколько людей пришло из Instagram и сколько из них оплатили.
Для метки подходят латинские буквы, цифры, `_` и `-`.

Специальная метка `?start=pay` сразу показывает кнопку оплаты. Её удобно ставить в сторис «вступить в клуб».

## Команды

**Для всех:** `/start`, `/subscribe`, `/status`, `/remind`, `/terms`, `/paysupport`

Команды `/terms` и `/paysupport` Telegram требует от ботов с оплатой. **Замени в них тексты на свои.**

**Для тебя (ID из `ADMIN_IDS`):**

| Команда | Что делает |
|---|---|
| `/stats` | люди, подписчики, выручка за 30 дней, где кто в воронке, источники |
| `/broadcast all` · `subs` · `free` | ответь этой командой на любое сообщение (текст, фото, видео, кружок), и бот разошлёт его выбранной группе |
| `/give 123456789 30` | выдать доступ вручную, например тому, кто оплатил переводом |
| `/refund 123456789 charge_id` | вернуть звёзды и закрыть доступ (charge_id приходит в уведомлении об оплате) |

## Как менять тексты воронки

Открой `content.json`:

```json
{
  "delay_hours": 48,
  "text": "<b>Урок 2.</b> ...",
  "buttons": [{"text": "✨ Что внутри клуба", "action": "subscribe"}]
}
```

- `delay_hours` — пауза **после предыдущего** письма.
- В тексте можно писать `{name}` (имя), `{price}` (цена), `{title}` (название клуба), `{date}` (дата окончания доступа).
- Разметка: `<b>жирный</b>`, `<i>курсив</i>`, `<a href="https://…">ссылка</a>`.
- Кнопки: `"action": "subscribe"` (оплата), `"miniapp"` (Барометр), `"remind"` (напоминания), `"status"`, либо `"url": "https://…"`.
- Письма можно добавлять и удалять. После правки перезапусти бота.

Новые письма получат те, кто ещё не дошёл до этого места. Тем, кто уже прошёл воронку, письма повторно не придут.

## Что проверить перед запуском

- [ ] Цена в `content.json → product`. Название уже стоит: «Точка сборки».
- [ ] Свои тексты в `terms` (оферта) и `paysupport` (контакт).
- [ ] `MINIAPP_URL`: ссылка на Барометр по https (например, GitHub Pages). Если её нет, кнопка Барометра просто не показывается.
- [ ] Тестовая оплата. В @BotFather есть тестовые токены ЮKassa. Звёзды можно проверить на себе, а потом вернуть командой `/refund`.
- [ ] Для ЮKassa: сверь `vat_code` в `core.py` со своей системой налогообложения. Сейчас стоит `1`, то есть «без НДС».
